# guess-plugin

### 介绍
- Yunzai-Bot的小型插件，提供一些小玩具。

安装
推荐使用git进行安装，以方便后续升级。在BOT根目录夹打开终端，运行

// 使用github
```
git clone --depth=1 https://github.com/Small-JiaJia/waste-plugin.git plugins/waste-plugin.git
pnpm install -P
```

### 更新插件
没有内置更新功能，更新请手动拉取本项目
